# Teaching

The teaching catalog lists courses and tutorials offered through the site.

## Language

**Current course**

A course listed before the Archive in the teaching catalog.

**Course entry**

The address that opens the default term for a course or tutorial.

**Default term**

The first term displayed for a course or tutorial in the teaching catalog.

**Image-based slide deck (图片版课件)**

A deck played from the three-digit `.jpg` files directly in its directory. The main slide and thumbnail strip use the same numbered sequence.

# Research and Projects

## Language

**Research entry**

A research result displayed on the Research page.

**Project entry**

A project displayed on the Projects page.

# Site Checks

## Language

**Site reference**

A link or resource URL that resolves to an address on the site.

**Site check status**

A site check is `completed` when every required check ran, even if it found content warnings. It is `incomplete` when at least one required check was blocked or ran only in part.

**Content warning**

A finding about the built site, such as a missing schedule or a broken link. A missing required output counts once per file path and keeps the first reporting source. Broken references to the same target count separately for each referring page.

**Incomplete reason**

A record of an affected check and the cause that prevented it from finishing. The report deduplicates and counts incomplete reasons separately from content warnings.
