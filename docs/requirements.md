# 站点需求文档

本站是 WU Xiaokun 的个人与学术站点。访客可以了解站点作者、查阅研究和项目，并获取课程资料。维护者可以发布内容、增加学期，并通过本地预览和构建检查核对生成结果。

## 现状基线

| 编号 | 场景 | 验收标准 |
| --- | --- | --- |
| REQ-01 | 访客查找站点内容 | 首页显示欢迎标题和 About 导引。主导航的 Home、Research、Projects、Teach 和 About 分别打开 `/`、`/research/`、`/projects/`、`/teach/` 和 `/about/`。About 展示作者的个人介绍。 |
| REQ-02 | 访客浏览研究成果和项目 | Research 和 Projects 按内容数据展示条目。条目的标题、缩略图以及已配置的详情、下载或外部链接可从列表访问。 |
| REQ-03 | 学生查找课表与课件 | 教学目录先列出当前课程，再列出归档课程。课程和教程按目录中声明的顺序展示学期链接。学期链接打开对应课表或教程，所选课程资料链接打开相应课件或下载文件。 |
| REQ-04 | 学生通过现行课程入口访问课程 | 课程入口打开默认学期，并提供指向同一学期的可点击链接。新增学期后，课程入口打开新的默认学期，历年课表继续通过原 URL 访问。课程目录迁移导致地址变更时，维护者更新教学目录并通知学生使用新地址。 |
| REQ-05 | 维护者更新并预览内容 | 更新页面或条目数据后，`make serve` 可用于查看改动。新增学期时，按课程既有命名方式添加课表，在教学目录数据中把新学期列为首项，并核对目录顺序、课程入口、历史链接和课件。 |
| REQ-06 | 维护者检查生成站点 | `make check` 构建站点。Jekyll 构建失败时命令返回失败。构建成功后，检查告警及检查未完成信息供维护者在命令输出或 GitHub Actions 的 **Site check** 摘要中审阅，命令仍返回成功。专项检查覆盖页面结构、课程入口、学期顺序、已登记课表的存在性和三个列表的缩略图 URL。 |
| REQ-07 | 维护者发现全站生成页面中的断链和缺失资源 | 构建后检查覆盖所有生成的 HTML，包括历史课表和独立课件。静态链接和常见资源引用的告警能定位到引用页面，给出原始引用及原因。检查仅访问本地生成文件，沿用 REQ-06 的告警和退出规则。具体覆盖范围见[架构设计](architecture.md#站内引用检查)。 |

## 维护方式

以 PR 为变更单位。站点行为或验收方式改变时更新对应需求，保留需求编号。模块职责或数据流变化时同步更新[架构设计](architecture.md)。在 PR 中说明受影响的页面或学期，记录构建与预览结果，并附上已有的相关议题链接。

术语见 [CONTEXT.md](../CONTEXT.md)，构建和预览命令见 [AGENTS.md](../AGENTS.md)。
