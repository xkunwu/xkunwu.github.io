# WU Xiaokun's personal homepage

> This is the code base of [my personal homepage](https://xkunwu.github.io/).

## Why use [GitHub Pages](https://pages.github.com/)?
Markdown is much easier to write - people can concatenate on the content, rather than the messy format tags.
Besides, GitHub is great for code sharing and project management.

## Check the site

Run `make check` to build the site and review its warnings. It checks the generated page structure, teaching term order and redirects, links in current default terms and Research and Projects entries, and thumbnails in all three lists. Local HTML links are also checked for matching anchors.

The terminal and the GitHub Actions run summary group warnings by the source file to edit. Post-build warnings are advisory. A failed Jekyll build returns a nonzero exit status.
